# 备案与资质要求

上架前绕不过去的合规部分。**结论先行：APP 备案是硬性前置条件，软著建议默认办理。**

## 一、APP 备案

### 法律依据

- 《工业和信息化部关于开展移动互联网应用程序备案工作的通知》（2023）
- 《中华人民共和国反电信网络诈骗法》第二十三条：设立移动互联网应用程序应当按照国家有关规定
  向电信主管部门办理许可或者备案手续

备案主体是 APP 主办者。由网络接入服务提供者（如华为云）或分发平台代为履行备案手续，
最终由主办者所在省级通信管理局审核。

### 谁要备案

- **所有提供互联网信息服务的 App**，含小程序、快应用等分发形态；
- 同一款 App 有多个包名、或同时有应用和元服务，**所有包名都要备案**；
- 同一款 App 已在安卓/iOS 备案过，**新增鸿蒙平台要走「变更备案」**添加平台，而不是重新备案。

### 备案前要满足的资源要求

APP 主办者使用的域名、IP 地址等网络资源需符合《互联网域名管理办法》《互联网IP地址备案管理办法》等要求。
也就是说，如果你的 App 有后端域名，**域名本身要合规、要能对应上主体**。

### 流程

1. **准备材料**
   - 主体信息（个人：身份证；企业：营业执照、法人信息）
   - App 信息（名称、包名、平台、图标、功能描述）
   - 域名 / IP / 服务器信息
   - 负责人信息 + 手机号（用于工信部短信核验）
2. **提交备案申请**：从华为云代备案入口提交（App 由华为云接入时在华为云备案）。
3. **接入服务商初审**：华为审核资料完整性与真实性。
4. **提交至通信管理局**：主体负责人先后收到「华为通知短信」和「工信部短信验证码」。
5. **工信部短信核验（关键，别漏）**：必须由备案负责人到工信部网站完成短信核验，
   未完成核验则申请不会进入管局终审。
6. **管局终审**。
7. **下发备案号**。

### 时间与并行建议

- 从提交到下发备案号通常需要数周（常见 **5~20 天**，视省份管局和资料情况浮动）。
- **建议在开发阶段就并行启动备案**，尤其是个人主体第一次备案，不要等开发完成才动手。
- 同理，**软著登记周期更长**（普通登记约 1~2 个月），也建议同步启动。

### 没备案的后果

- **应用市场侧**：安装按钮置灰，提示"该应用因未完成 APP 备案，暂不提供下载"；
- **上架审核侧**：备案校验不通过，无法通过审核。

### 常见坑

1. 漏做工信部短信核验，备案卡在"已提交管局"状态很久。
2. 备案名称和应用上架名称、软著名称不一致（见[名称一致性](01-开发者注册与上架发行.md)）。
3. 已有安卓备案却直接新增鸿蒙包名当新备案提交 —— 应走变更备案。
4. 个人主体备案时，域名持有者与备案主体不是同一个人。

## 二、资质清单

| 资质 | 是否必须 | 说明 |
| --- | --- | --- |
| APP 备案号 | **必须**（联网应用） | 见本文第一节 |
| 软件著作权 | 官方口径"视品类 / 非必选但建议"；实际审核常被要求 | 见下文 |
| 特殊行业资质 | 视品类 | 金融、医疗、直播、地图、票务等需企业资质 |
| 隐私政策 + 用户协议 | **必须** | 需可公网访问的链接 |
| 内容分级问卷 | **必须** | 年龄分级 |
| 第三方 SDK 清单 | **必须** | 需在隐私政策中逐一明示 |
| 个人开发者承诺函 | 个人开发者必须 | 官方提供模板 |

### 软件著作权

- 官方文档的措辞是"软件著作权证书为非必选资质，但建议您申请"；应用资质审核要求里对非游戏类应用标为"视品类"。
- 但**实际提交时经常被要求补交**，且很多应用商店（含其他厂商）在中国大陆上架都要求软著，
  因此**建议默认办理**。
- 三种可选形式（选一）：《计算机软件著作权登记证书》、《APP电子版权证书》、《软件著作权认证证书》。
- 普通软著登记免费，但周期约 **1~2 个月**；加急 / 电子版权认证为付费（数百到上千元），几天到十几天可出。
- **名称必须与商店应用名称、APP 备案名称一致。**
- 如果你是代理别人的版权，还需提供版权授权书。

## 三、游戏类（个人开发者基本不可行）

游戏需要：

1. 《计算机软件著作权登记证书》或《APP电子版权证书》或《软件著作权认证证书》（三选一）；
2. 《网络游戏出版物号（ISBN）核发单》或《关于同意出版运营移动网络游戏的批复》；
3. 若上传者不是版号批文中的运营单位，需提供运营单位的版号授权书；
4. 版署实名认证：在网络游戏防沉迷实名认证系统上与华为平台关联获取 bizID，并在 AGC 提交审核；
5. 游戏名称须与软著名称一致，登记号需可在中国版权保护中心查询。

**版号本身需要企业主体申请，所以游戏对个人开发者基本关闭。**

## 四、特殊行业资质（举例）

以下类目均需**企业主体 + 对应许可证**，个人开发者无法覆盖：

| 类目 | 典型资质 |
| --- | --- |
| 金融理财 / 股票基金 / 贷款 | 《金融许可证》或地方金融批文，部分需《增值电信业务经营许可证》 |
| 征信机构 | 人民银行省级分支行出具的备案证明或《个人征信业务经营许可证》 |
| 贵金属 / 黄金相关 | 人民银行备案 + 交易所会员资格 + 合作协议 |
| 医疗器械 / 药品销售 | 《互联网药品信息服务资格证书》、经营许可/备案凭证 |
| 融资担保 / 小额贷款 | 《融资担保业务经营许可证》《小额贷款公司经营许可证》等 |
| 直播、微短剧、互联网地图、营业性演出票务、手机话费充值 | 结合应用核心功能与主营业务场景综合判断，通常需企业资质 |
| 具有舆论属性或社会动员能力的产品 | 安全评估报告 + 全国互联网安全管理服务平台审批截图 |

**资质文件格式要求**：原件拍照或彩色扫描，或加盖公章的复印件；必须在有效期内；
不可隔屏拍摄，边角完整、内容清晰（国徽不得遮挡）；色调背景一致、无反光；
水印只能一行且不遮挡重要信息；支持 JPG / PNG / BMP / PDF。

## 五、隐私合规（最容易被驳回的一块）

- 上架前需提供**可公网访问**的隐私政策，如实填写应用信息和隐私声明。
- **所有集成了第三方 SDK 的 App**，都要在隐私政策中逐一明示该 SDK 收集个人信息的目的、方式和范围，
  否则可能上架不通过。
- 权限申请必须与应用实际功能匹配，**不能超范围申请**。
- 不能在审核时用技术手段隐藏违规内容、上架后再开启。

## 六、个人开发者的硬性限制汇总

| 限制 | 说明 |
| --- | --- |
| 华为账号一键登录 | **不支持** |
| 获取用户手机号 | **不支持** |
| 获取收货地址 | **不支持** |
| 获取年龄段（游戏类能力） | **不支持** |
| 商店展示名称 | 个人姓名（不是 App 名/公司名） |
| 特殊行业类目 | 基本无法上架（需企业资质） |
| 游戏类 | 基本无法上架（需版号，版号要企业主体） |

登录场景下个人开发者可用：**华为账号登录**、**静默登录**。

## 七、常见驳回原因（速查）

- APP 备案缺失，或备案名称与上架名称/软著名称不一致
- 软著缺失 / 名称不一致 / 登记号查不到
- 隐私政策链接打不开，或未明示第三方 SDK
- 权限申请与功能不匹配
- 应用截图、描述与实际功能不符
- 分阶段或隐藏式违规内容
- 资质文件格式不合规（隔屏拍摄、水印遮挡、过期）
