## 依赖关系

```
第一部分 入门 ──> 能写代码 ──┐
第二部分 工具链 ─> 能跑起来 ──┼──> 产出可上架的 HAP/APP 包 ──> 上架成功
                              │                                  ↑
开发者注册认证 ────────────────┘                    备案 / 软著 ──┘
```

**备案与软著都有天级到月级的等待期，建议在开发阶段就并行启动**，不要等开发完成才动手。

> 资料基于 2026-10 时点整理，华为侧政策更新频繁，关键决策前请复核官方页面。
